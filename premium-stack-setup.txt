create-next-app was not run in place. The Next.js App Router scaffold is

IMPLEMENTATION STACK DEVIATION

PRD 06's initial draft specified Next.js 14. The first install reported a
critical audit finding, and the official support policy now lists 14.x as
unsupported. The implementation uses Next.js 15.5.26 with React 19, the
smallest supported major-version upgrade. Revisit PRD 06 before deployment so
the stack lock matches the implementation. Sources: https://nextjs.org/support-policy
and https://nextjs.org/blog/nextjs-security-update-september-22-2026

PHASE-SCOPED / CONDITIONAL INSTALLS

Round 3 added one shadcn/Radix primitive and restyled it with AURELIA CSS:

  npx shadcn@latest init --template next --base radix --no-css-variables --no-rtl --no-pointer --preset nova -y
  npx shadcn@latest add dialog
  npm uninstall cn class-variance-authority shadcn tw-animate-css

The retained dialog wrapper is in src/components/ui/dialog.tsx. Radix supplies
dialog focus trapping, Escape handling, and focus restoration. The generated
button and Tailwind v4 theme were not retained; the project remains on Tailwind
3 and uses its existing clsx/tailwind-merge utility. The shadcn CLI is invoked
through npx and is not a runtime dependency. Search, cart, quick view, wishlist,
size guidance, and toast behavior use small project components built around
that dialog primitive.

LENIS + GSAP SYNCHRONIZATION (Round 2 LenisProvider):

  const lenis = new Lenis({ lerp: 0.1, smoothWheel: true });
  lenis.on('scroll', ScrollTrigger.update);
  gsap.ticker.add(t => lenis.raf(t * 1000));
  gsap.ticker.lagSmoothing(0);
  // after mount:
  ScrollTrigger.refresh();

Round 3 motion is kept out of the initial route bundle with a dynamic
MotionEngine import. Ken Burns ScrollTriggers for editorial images are
registered by IntersectionObserver as those images approach the viewport.
